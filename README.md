# 🌐 LinguaSphere AI

### AI-Powered Real-Time Translator

LinguaSphere AI is a futuristic AI-powered translation platform designed to break language barriers and enable seamless global communication.

It provides multilingual text translation, voice input, live conversation translation, and an immersive 3D user interface powered by modern web technologies and Gemini AI.

---

## ✨ Features

- 🌍 **Multilingual Translation** — Translate text between multiple languages.
- 🎙️ **Voice Translation** — Speak naturally and receive translated text.
- 💬 **Live Conversation Mode** — Supports bilingual conversations between two speakers.
- 🔊 **Text-to-Speech** — Listen to translated responses using browser speech capabilities.
- 🔄 **Language Switching** — Dynamically select source and target languages.
- 📋 **Copy & Replay** — Copy translated text or replay translated audio.
- 🧠 **Gemini AI Integration** — Context-aware AI translation.
- 🌎 **Interactive 3D Globe** — Visualizes global communication.
- ✨ **3D AI Translation Engine** — Futuristic AI-powered translation interface.
- 📱 **Responsive Design** — Works across desktop, tablet and mobile devices.
- 🎨 **Glassmorphism UI** — Premium futuristic visual experience.
